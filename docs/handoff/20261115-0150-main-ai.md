## 5. 排除记录（已试过/已被推翻，别再试）

1. **「改 Room 数据库能改会话分组」→ 无效**：设备无 `sqlite3`；proot python + sqlite 3.45.1 直改 `chats."group"` 当场成功（`integrity_check=ok`），但 App 运行时会把内存旧行整行写回，**杀进程重启仍回退**（实测 `None 1 / OAS安卓端适配 9 / 子任务 3`）。只能靠标题前缀识别（BG-25）。
2. **「文件 socket + chmod 666」→ 平台不支持**：API 35 的 `android.net.LocalServerSocket` 只有 `(String)` 与 `(FileDescriptor)`，名字建在 Linux abstract namespace；`android.system.UnixSocketAddress` 也不存在（`docs/BACKGROUND.md §结论 4`）。
3. **「wakelock 用 PowerManager」→ 必 NPE**：`app_process` 下 `getSystemContext()` 为 null，只能写内核 `/sys/power/wake_lock`。
4. **「游戏自持 `displayId:19` 屏幕锁」→ 错**：持锁者是 `system_server`（uid=1000）；`WorkSource{10386 com.netease.onmyoji}` 只是 top app 标签。
5. **「主屏能熄灭 = 假息屏」→ 不成立**：熄主屏不受该锁阻断；真被阻断的是「整机 suspend」（`mHoldingDisplaySuspendBlocker=true`）。
6. **「单棒上下文预算 ≤40K」→ 错**：判据是压缩阈值 179K。
7. **「必须他人 approve 才能合」→ 错**：单账号无法自批，项目用 Show 模式（CI 绿即合，D 的评审建议性）。
8. **「四段必须 4/4 才能合 main」→ 错**：4/4 是**发布**门禁，不是合并门禁。
9. **「`frames` 能判画面在动」→ 只在真实虚拟屏 displayId 上成立**；`displayId=-1` 时恒 -1。
10. **「子会话能自己找到工作区」→ 不能**：子会话没有工作区附件，指令里必须贴绝对路径，否则它去 `/sdcard` 瞎找。
