## 5. 排除记录（已试过、不要再试 —— 全文）

1. proot(`super_admin:terminal`) 里的 `ps` 是 Ubuntu procps，**不支持 `-o PID,ARGS`**（报 `unknown user-defined format specifier "PID"`）；设备进程查询一律走 `super_admin:shell`（toybox）。
2. proot 无法写 `/data/local/tmp`（`cp` 报 `Permission denied`）；从 git 取文件改用重定向到 `/sdcard/Download/`。
3. `main` 是受保护分支：直推必被拒（`! [remote rejected] main -> main (protected branch hook declined)` + `remote: - Required status check "static-gate" is expected.`）→ 一律 分支 + PR + 门禁绿后 squash。
4. push 偶发 `GnuTLS recv error (-110): The TLS connection was non-properly terminated` → 重试即可；**判定是否真推上去用 `git ls-remote --heads origin`，不信 push 回执正文**。
5. `monkey` 禁用（BG-31：会把 `accelerometer_rotation` 写成 1）→ 拉起前台一律 `am start -n <pkg>/<activity>`。
6. 直改 Room 库 `chats."group"` 会被 App 内存旧行写回（BG-25），不追分组；靠标题前缀识别会话。
7. `git commit -F -` 配 heredoc 在 `terminal` 里会被吞字符 → 提交一律用多个 `-m`。
8. `rm -rf` 被安全策略拦（`Potentially dangerous command detected`）→ 换新目录名而不是删旧目录。
9. awk 自身命令行会含模式字面量 → 自命中（把 awk 误认成 daemon）；解决是靠 `app[_]process` / `oas[.]server[.]Main` 反字符类写法，⚠ 不要写成 `$2 != "awk"`（恒真，是假防护）。
10. toybox awk 对 `printf` 里的三元表达式报 `syntax error` → 改纯 `if`。
11. cgroup freezer 冻结时进程 CPU 也不涨 → 判「冻死」必须看 `/proc/<pid>/stat` 的**状态字母 `D`/`T`**。
12. **流程教训（最重要）**：主 AI 曾越位手写 `tools/hang_check.sh` 并自行评审，被用户两次纠偏 —— 写代码必须由唯一写手（A5）、评审必须由 D；越位产物已撤出 main。**新主 AI 不得再犯**。
13. proot 里直接跑 `git diff` / `git log` 会进 pager（`less`）→ **命令超时、后续命令全部卡死（`timedOut` + `context_preserved=false`）**；解法：先 `export GIT_PAGER=cat PAGER=cat` 或用 `git --no-pager …`；卡住时发 `q` 退出 pager。
14. `extended_chat:chat_with_agent` 发长指令 + 子会话长回复时偶发 `读取对话消息失败 … connection closed（重试5次）`，主 AI 自身也整轮返回空；对策：指令压短分批、用 `agent_status`/`read_messages` 轻量取回执。
15. proot 里 `git rev-parse --short main origin/main` 报 `fatal: Needed a single revision` → **分开跑** `git rev-parse main` / `git rev-parse origin/main`。
16. GitHub API 偶发 503 限流（D 拉 `raw.githubusercontent.com` 时遇到）→ 结论只标「未找到」，**不要写成「不存在」**。
