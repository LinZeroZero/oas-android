## 7. 环境 / 工具坑（踩过，别重踩）

- `super_admin:shell` 默认 cwd 可能是**已删目录** → 任何 `app_process` 必先 `cd /data/local/tmp`，否则 JVM 启动期 SIGSEGV
- `nc -U @name` **不支持抽象命名空间**（ENOENT）→ 连 daemon 抽象 socket 只能用自编 `KbClient`（临时物，不入库）
- proot 里写不了工作区 `dist/`（Permission denied）→ 落盘走 root shell；`rm -rf` 会被 shell 判「Potentially dangerous」→ 拆成 `rm -f` + `rm -r`
- `dumpsys power` 的 `displayId:N` 跟当前前台画面走 → **禁止写死 19**
- `am start --display N -n <pkg>/.tag0` 看似成功，但游戏内部跳 `.Client` 丢 `launchDisplayId` 落回主屏（BG-27）
- 本机 `cmd display` **无** power-off 子命令（那是 Android 15+）；熄屏只能 `input keyevent 26`
- `--cmd` 是**一次性进程**（自建 SocketServer，跑完 exit），不连常驻 daemon；要长期持屏必须「常驻 daemon + 独立客户端」，别混用
- 子会话 `chat_with_agent` 常报「结果缺失」→ **以磁盘文件时间戳/大小为准**，不以回执为准

## 8. 硬约束（违反即返工）

- 绝不 `wm size` / 改 dpi：识别画布**恒 1280×720**
- 不注册开机自启：无 BootReceiver / JobScheduler / AlarmManager，不申请 `RECEIVE_BOOT_COMPLETED`
- 工具链：Gradle **8.14.3** / AGP **8.13.2** / minSdk **26** / targetSdk **35** / **arm64-v8a**；构建只用 `./gradlew` + `tools/gate.sh`
- ADR-0001：只准 **PARTIAL 语义**锁（内核 sysfs），**禁** `SCREEN_BRIGHT_WAKE_LOCK` / `FULL_WAKE_LOCK`
- 测试机是用户**主力机**：任何占前台 / 熄屏实验后必须把 Operit 拉回前台；改系统级设置先征得同意
- git 纪律：小步提交、只 `git add <具体文件>`；**禁** `git add -A` / `commit -a`；**禁** `checkout` / `reset` / `merge` / `tag`（除非明确指派）
