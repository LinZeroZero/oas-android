## 3. 快路 0 命中的真因：Android mksh 算术是 32 位，`hts / 1000` 溢出

在设备上把 `hb_frames` 抽出来单跑（`set -x`）：

```
+ hts=1794929505645
+ hpid=16447
+ '[' 16447 '=' 16447 ']'      # pid 校验通过
+ date +%s
+ now=1794929511
+ age=1795296330              # ← 应该是 6，实际是 1.79e9 级垃圾值
+ '[' 1795296330 -le 5 ']'
+ return 1                    # 快路必然返回「给不出数」
```

`1794929505645 / 1000` 在 32 位整数下先截断成 `-366824083`（再除 1000 得 `-366824`），`now - (-366824)` 就成了 `1795296335`。
所以 `[ "$age" -le "$HB_MAX_AGE" ]` 永远为假 → 快路从未生效，`frames` 只剩「app 通道每 5 拍一次」。

证据：`hb_frames 36 16447` → MISS；`hb_frames 36 0` → MISS0；同一时刻 `tail -1` 心跳文件内容完全正常。

## 4. 报告判 FAIL 的原因（不是缺陷）

`daemon 缺失 1/31 个样本；游戏缺失 1/31 个样本` —— 首拍（23:29:41）早于挂机链建立（23:29:45+），首拍如实记为 `dpid=0 / gpid=0 / did=- / frames=n/a`。
判定规则「有任一拍 pid=0 → FAIL」没有区分「前置启动期」与「中途掉线」。记 nit：长跑不受影响（首拍只 1 个），但小样本冒烟会被判红。
