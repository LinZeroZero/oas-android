## 3. 四段原始数字
### 3.1 先证伪一个错误测法：整行 strip 喂 rec
整行 `2412×80` 裁剪 → rec 输出乱码，分数却"看起来还行"，**说明分数不能自证正确**：
| 裁剪 | 分数 | 输出 |
|---|---|---|
| y=30-110 | 0.724 | `：1555万4525284+#34万中` |
| y=110-190 | 0.500 | `昌蓬，阳烯获充洲夜周备大人在幸运南端奶活动中最` |

原因：rec 是**单行**模型，一行里并排十几个控件必然崩；**不能用整行做验收**。

## 4. 结论与限制
- **可用**：真实阴阳师 UI 文字在 **单 ROI** 下 rec 可读，干净标签 0.73–0.79。
- **可用阈值**：非文字区分数 0.03–0.22 → **score ≥ 0.5 可过滤美术区**（本样本经验值，非产品阈值）。
- **不可用**：整行/多控件裁剪；这正说明 **det（BG-41）或精确 ROI 是前提**——OAS 的 `Single` 系本就给固定 ROI，故现有 rec 接入对 Single 有效。
- **限制**：单界面、单帧、n=1 截图（D-018）；未在 APK 内复测；截图已按收工纪律删除（`/sdcard/oas_*` 清空），BG-41 若要复用输入需重采。
