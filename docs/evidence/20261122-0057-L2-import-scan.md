## 5. 结论：**不可构建，硬门槛 4 个（module/tasks 必需）**
判据 = Chaquopy 原生包索引（`https://chaquo.com/pypi-13.1/`，138 个原生包）逐个探活，缺包即 404：

| 包 | 索引探活 | 为什么是硬门槛 |
|---|---|---|
| `pydantic-core`（→ `pydantic` 2.x） | **404** | Rust 扩展；`requirements.txt` 钉 `pydantic==2.10.0` + `pydantic-core==2.27.0`；代码用 v2 API（`tasks/ActivityShikigami/config.py:4 model_validator`）；**v2-only 命中 13 文件 / 31 处**（`model_validator` 10、`field_validator` 13、`model_dump` 6）→ 无法降 v1 绕开 |
| `onnxruntime` | **404** | `requirements.txt` 钉 `onnxruntime==1.16.3`（via `ppocr-onnx`）；`module/ocr/ppocr.py:1 import ppocronnx.predict_system` 是 OCR 主路径 |
| `av`（PyAV） | **404** | `module` 内 2 处 import；FFmpeg 原生 |
| `opencv-python` | 有目录但只有 `cp310-cp310-android_24_arm64_v8a` / `cp38-cp38-android_21_arm64_v8a` | 与 `app/build.gradle` 既有注释一致：**无 cp313 轮子** → 只能继续走 Java AAR + Python shim |

- `PySide6`（18 处）**仅 gui 专属**，属可砍范围，不构成门槛。
